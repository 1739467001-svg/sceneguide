5. **赛道选择：只投 Machine Pay 一条**（2026-11-24 核实官方规则后修正）
   - 官方《参赛规则》原文：**「一次报名，可跨赛道提交作品。每条赛道最多提交 10 件独立作品，
     同一作品不得跨赛道重复投稿。」**
     ⇒ 同一个作品不能同时投多条赛道。我们这**一个**作品只投 **Machine Pay**。
   - 选它的理由：作品形态就是「AI 按量付费」（HTTP 402 挑战 + 按次计费 + service_id），
     与该赛道的接入能力完全对应；且机器赛道**只发一个**最佳探索奖（¥10,000 ×1），
     竞争池是五条赛道里最小的。
   - ❌ 不投 Skill Pay：官方细则要求 Skill Pay 赛道的作品**必须上架 skillpay.alipay.com
     的公开货架**，并把商品详情页链接填进作品链接——我们没上架，填了也不计分。
   - ❌ 不投 Vibe Pay：接入【Vibe Pay 基础收款能力】的话，还需另行开通【网页应用收款】
     才能让去重付费用户数计入统计；而【智能收款套件】又与本作的 Agent 按量付费形态不是一回事。
     硬凑一条等于拿一个更弱的作品去占一个本该留给 Machine Pay 的注意力。
   - 官方奖金结构（备查）：Vibe Pay 一等 ¥30,000×1 / 二等 ¥15,000×3 / 三等 ¥5,000×5；
     Skill Pay 一等 ¥10,000×1 / 二等 ¥5,000×3 / 三等 ¥3,000×5；
     Machine Pay / Token Pay / Agent Pay 各一个最佳探索奖 ¥10,000×1。
     **同一赛道内一位参赛选手最多只有 1 个作品可获奖**——所以每条赛道只需要投一个最好的。
