### 一句话介绍（≤50 字）

```
基于真实 OpenStreetMap 地理拓扑的场景导览服务：Agent 自己发现、自己支付、拿到可核验的路线，按次计费。
```

### 详细介绍（约 300 字）

```
「三维问路」把真实地理变成可对话、可交易的服务。

产品侧：游客对它说「从A教学楼到C教学楼怎么走」，它基于 OpenStreetMap 真实步道拓扑计算路线
（134 个真实地标、381 对实测步道连通），三维场景里路线沿真实步道行走；
研学任务模式进一步把它变成可交付的教育产品——线索链、逐站打卡（乱序/跳站被服务端拒绝）、
全部走完后才颁发覆盖实际打卡记录的可核验证书。

支付侧：整套服务通过支付宝 A2M 智能收（HTTP 402）按次计费——商家本地构造 Payment-Needed 账单
（字典序拼接 + RSA2 签名），买方 Agent 携 Payment-Proof 重试，服务端完成五项业务核验、
幂等履约与履约回执。官方按量付费不提供自动计量，本项目自建四维用量计量层
（调用次数/token/路径长度/点位数），所有数字可核验。
多额度商品（十次导览包）另有真实权益台账：付清后次数余额到账，后续调用逐次扣减，
不重复收费，余额耗尽才回到 402。

增长侧：渠道归因（首触绑定）、免费试看限流、转化漏斗按渠道拆分；
订单按来源标注 demo/api，自测订单永远不计入「真实付费用户」——反刷量是设计出来的，不是口头承诺。
**订单核验卡**：每笔已支付订单可生成一张公开可分享的核验页（脱敏交易号 + 证据哈希 + 距离端点，
不含答案内容），「我也要问」带渠道归因回流——可核验性从卖点变成传播机制。
站点另设社区反馈墙：留言、点赞、线程回复、举报与撤回全部可用，墙上只出现真实提交的内容。
```

## 各赛道提交说明

### Machine Pay（主赛道 · 实现最完整）

```
作品：三维问路 · SceneGuide（按量付费资源）
形态：REST API，基于 HTTP 402 的 A2M 智能收
接入点：
  - 商家本地构造 Payment-Needed（不调用预下单 OpenAPI，本地 RSA2 签名）
  - alipay.aipay.agent.payment.verify（含 client_session 原样透传）
  - alipay.aipay.agent.fulfillment.confirm（履约回执）
  - 五项业务核验 + trade_no 防重复履约 + 订单先落库再返回 402
  - 权益额度台账：多额度商品付清后发放次数余额，调用直接扣减，耗尽回到 402
计费：按次（¥0.50），四维用量计量留痕（guide_call / tokens / distance_m / poi_count）
演示：http://121.43.80.231/sceneguide/#protocol 真实报文；#demo 现场真实支付
验收：bash scripts/verify.sh（62 项，含真实支付、幂等与额度扣减验证）
```

### Vibe Pay（交付形态 · 主展示）

```
作品：三维问路 · SceneGuide（网页应用）
形态：网页应用（可安装 PWA 桌面应用形态；IP/HTTP 直连时给出「创建快捷方式→窗口中打开」的等价路径，HTTPS 后恢复一键安装——安装能力与运行环境诚实对齐，不做做不到的承诺）
说明：完整可操作的三维导览工作台：免费试看（每天 3 次）→ 402 支付挑战 →
  一键真实支付（沙箱）→ 交付可核验结果。研学任务模式（¥9.90）提供
  「线索链 → 打卡 → 完成证书」的可交付教育产品。
  另含社区反馈墙：留言、点赞、线程回复、举报与撤回，墙上只出现真实提交的内容。
收款：当前底层走 A2M 402 按次计费；nowpay/观猹路径按 D0 实验结果补充（见参赛方案）。
演示：http://121.43.80.231/sceneguide/
```

### Skill Pay（衍生形态）

```
作品：scene-guide 商家技能包
形态：SKILL.md（含完整工作流与异常处理说明，商家侧随作品交付的装载文件）
安装：把本 SKILL.md 提供给买方 Agent 宿主装载（或由对话 Agent 按描述直接调用 REST 接口）；
      支付环节复用支付宝官方 alipay-pay-for-402-service 技能
```

### Agent Pay（交易链路）

```
作品：Agent 自主采购链路（发现 → 支付 → 交付）
形态：MCP 服务端（POST /mcp，JSON-RPC 2.0）
  - tools/list 暴露 scene_guide（annotations.paid=true）与 scene_guide_scenes
  - 调用 scene_guide 未带凭证 → 返回 payment_required 与账单，指示交给
    alipay-pay-for-402-service 技能
  - 携 payment_proof 回调 → 验付并交付结构化结果
演示：http://121.43.80.231/sceneguide//#transaction 第一环为页面实时调用 MCP 端点的真实结果
```
