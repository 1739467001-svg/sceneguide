## 录制注意

- 浏览器开**新的无痕窗口**（避免旧 cookie 影响试看次数），先访问 `https://121.43.80.231/sceneguide/?ref=demo` 让首挑战就绪
- 录屏区域只框浏览器窗口（1360×900 左右），不要带桌面
- 第 3/5 步的沙箱支付要等 5–8 秒，**别切走**——等待本身是真实性的证据
- 录完导出：QuickTime → 编辑 → 裁剪头尾 → 导出 1080p
- 文件命名：`scene-guide-demo-<日期>.mp4`，随作品提交 + 发社群
- **每次 UI 变更后必须重录**（2026-11-23 的教训）：11-20 的旧版视频里首屏数字与档位表
  都已过时，评委「看视频 → 看站点」会立刻发现对不上

  把返回的 `scene_guide / paid=true` 露 3 秒；再跟一条
  `node scripts/verify-mcp-flow.mjs` 的全绿汇总（21 项端到端）

- **验收全套**：`bash scripts/verify.sh` 跑一遍，快进展示全绿汇总（88 项，
  含 MCP Agent 链路 21 项与买家账户中心 17 项两条端到端）
