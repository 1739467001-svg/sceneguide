01问题与方案

通用大模型答不了「从A教学楼到C教学楼怎么走」——不是不聪明，是没有地理拓扑。我们把真实 OpenStreetMap 步道网络变成一个可计费、可核验、可被 Agent 自动采购的在线服务：Agent 自行发现服务 → 自行完成支付 → 拿到带证据哈希的路线。三维场景里，113 栋建筑由 OSM 真实多边形轮廓拉伸而成，路线沿真实步道行走。

03支付集成（Machine Pay · 全链路）

环节实现要点
① 402 支付挑战商家本地构造 Payment-Needed（字典序拼接 + RSA2 签名），订单先落库再返回 402；不调用预下单 OpenAPI
② 买方支付报文原样交给支付宝 alipay-pay-for-402-service 技能，引导用户付款
③ 携凭证重试Payment-Proof 重试同一请求；client_session 原样透传
④ 验付与五项核验active / amount / out_trade_no / resource_id / trade_no 未重复履约
⑤ 幂等履约与回执UNFULFILLED→PENDING_CONFIRM→FULFILLED 状态机；履约回执失败可用同一凭证重试，不重复生成资源

MCP 发现：POST /mcp（JSON-RPC 2.0），tools/list 暴露 scene_guide（annotations.paid=true）与 scene_guide_scenes；tools/call 付费工具返回 payment_required 与账单。另有 llms.txt 面向 Agent 描述全部端点与计费。

04商业化设计

档位生产价交付物

首发半价 trial¥4.95/次（限时）同单次导览——社群首发转化档，同一服务内容独立定价（注册价=实收价约束）
  • 自建计量层：官方按量付费不提供自动计量——自建四维计量（调用/token/路径长度/点位数），只记录不参与扣费（平台要求注册价=实收价）
  • 反刷量口径：订单按来源标注 demo/api，自测订单永远不计入「真实付费用户」；免费试看双限流（访客 + IP 哈希，NAT 容忍量级）
  • 增长闭环：首触渠道归因 → 转化漏斗按渠道拆分（含近 7 天周维度）→ 订单核验卡让每笔已支付订单成为可分享的传播物（ref=share 归因回流）

05数据与可核验性

  • 同一条 OSM 管线构建 3 个场景：浙江工商大学下沙校区（134 地标/597 边）、良渚文化村（36 地标/635 边）、演示园区——管线可泛化，站点内一键切换
  • 路线 = 场景图 Dijkstra 最短路；输出 geometryHash（SHA-256）覆盖节点与边，任何人可复算
  • 诚实兜底：OSM 步道碎片化区域退化为明确标注的直距估算，绝不假装有路径；目的地图谋不到时诚实说「未收录」并列出可导航地标（实测抓到过 0 米 bug 并修复）

06工程亮点（全部实测踩坑）

  • Payment-Needed 嵌套结构与扁平签名子集不一致、字典序拼接、alipay-sdk 只吃 PKCS#1——三个官方文档没写清的坑，技术规格文档 §0.5 留档
  • Node 预编译产物坑（实测复盘）：better-sqlite3 v13.0.3 官方 linux-x64 预编译对文件型 DB 必 SIGSEGV（内存库却正常——极易误判为应用 bug）；升级 v13.2.0 修复。部署链路四坑复盘留档于仓库 deploy/服务器部署清单.md
  • 运维自愈：systemd 定时探活 /healthz（含 DB 字段），失败自动重启容器——「维持作品可用」是部署出来的，不是承诺出来的；自愈演练实测通过（停容器 → 15 秒恢复 healthy）
  • 官方条款逐条对齐（据开放平台《AI收》接入准备 / 产品介绍）： 准入支持个人账号（本作品以个人主体接入）｜费率单笔 1%、个人开发者 2026.4.15–12.31 零费率｜ 结算默认实时到账签约账号余额（新签约未满 90 日或连续交易未满 30 日次日结算）｜ 退款默认交易后 12 个月内原路退还、服务费一并退回｜买方需在支付宝 App 开通 AI 钱包； 官方另说明「AI收 产品暂不支持沙箱调试」——故本作品所用为官方 Skill 提供的匿名沙箱 （api_mock_service_id + 官方沙箱收银），正式环境注册真实 service_id 后切换
  • 本服务已被支付宝官方买方脚本端到端买通：用官方 Skill 内置的 local_402_sandbox_pay.py 去购买本服务——官方脚本自己发起请求、拿 402 账单、 走官方沙箱收银付款、携 Payment-Proof 重试，并由官方脚本自己校验交付证据， 结论原文「AI 按量付费沙箱服务端联调通过」。任何人都可复跑 bash scripts/official-buyer-check.sh 验证——不是自证，是主办方工具的判定
  • 已启用 HTTPS（Let's Encrypt 为裸 IP 签发的短期证书）：Chrome 会把 http:// 裸 IP 自动升级为 https://，无 TLS 时会硬拦截成空白错误页——现已直接给 121.43.80.231 上 TLS 并配 12 小时自动续期，评委点开链接直达作品；安全上下文成立 → Service Worker 正常注册 →「可安装 PWA」（桌面应用形态）真实可用
  • 隐私最小化：不存任何个人信息，IP 只存加盐哈希
  • 基线安全响应头（nosniff/SAMEORIGIN/Referrer-Policy/COOP）；无 CDN 依赖可离线运行
